# Chashmyalla Lens Stock System

Enterprise-grade lens inventory and pricing management with Firebase.

## Quick Start

1. Create GitHub repo: `chashmyalla-lens-stock`
2. Upload these files (keep filenames EXACT, NO .txt!)
3. Setup Firebase Realtime Database
4. Deploy to Vercel with Firebase env variables
5. Share URL with staff

## Files Required

```
package.json          (rename from package.json)
vite.config.js        (rename from vite.config.js)
index.html            (rename from index.html)
main.jsx              (rename from main.jsx)
ChashmyallaApp.jsx    (rename from ChashmyallaApp.jsx)
index.css             (rename from index.css)
tailwind.config.js    (rename from tailwind.config.js)
postcss.config.js     (rename from postcss.config.js)
.gitignore            (rename from gitignore.txt)
.env.example          (rename from env-example.txt)
```

## Deploy Steps

1. GitHub: Create repo & upload all 10 files
2. Firebase: Create Realtime Database & get config
3. Vercel: Import repo, add 7 Firebase env variables
4. Deploy & test

Done! System is live.
